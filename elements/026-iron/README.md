# Iron

This is a key part of the Klipper replacement strategy. Someone might look at this and think "Replacing Python with Lua? Meh." and they'd be sorely mistaken.

There's a lot to unpack here, as this is just getting started (written Aug, 2026) but the gist of it is that Lua is on the job, and can *easilY* reach down to C whenever it needs it as it is hosted inside a C server. 

The parts anyone cares about are all Lua - the C underpinnings are not at all related to anything to do with why anyone is here.
