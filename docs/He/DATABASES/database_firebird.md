# database_firebird.lua

## Overview

`database_firebird.lua` defines Firebird-specific macros for the Helium migration system. Firebird 4 is a real SQL engine (`libfbclient`), not an alias of PostgreSQL. `${SCHEMA}` is empty. The database file (`hydrogen_test.fdb` or `hydrogen_demo.fdb`) is the isolation boundary.

Lookup 030 key 6 is the Firebird dialect id (`${DIALECT}` = `6`).

Install and SuperServer notes: [extras/firebird/README.md](/elements/001-hydrogen/hydrogen/extras/firebird/README.md).

## Data Type Mappings

| Macro | Firebird type | Description |
| --- | --- | --- |
| `INTEGER` | `INTEGER` | 32-bit integer |
| `INTEGER_BIG` | `BIGINT` | 64-bit integer |
| `INTEGER_SMALL` | `SMALLINT` | 16-bit integer |
| `FLOAT` | `FLOAT` | Binary32 |
| `FLOAT_BIG` | `DOUBLE PRECISION` | Binary64 |
| `TEXT` | `VARCHAR(255)` | Short text |
| `TEXT_BIG` | `BLOB SUB_TYPE TEXT` | Large text |
| `JSON` | `BLOB SUB_TYPE TEXT` | JSON stored as text until Firebird 6 |
| `TIMESTAMP_TZ` | `TIMESTAMP WITH TIME ZONE` | Timestamp with time zone |
| `DATETIME` | `TIMESTAMP` | Timestamp without time zone |
| `SERIAL` | `INTEGER GENERATED BY DEFAULT AS IDENTITY` | Identity column |
| `VARCHAR_*` / `CHAR_*` | `varchar(n)` / `CHAR(n)` | Sized character types |
| `NOW` | `CURRENT_TIMESTAMP` | Current timestamp |
| `PRIMARY` | `PRIMARY KEY` | Primary key constraint |
| `UNIQUE` | `UNIQUE` | Unique constraint |

`INSERT … RETURNING` is native. `${INSERT_KEY_RETURN}` is the word `RETURNING` followed by a space.

## Base64 and SHA-256

Both are native. No UDR.

```lua
BASE64_START = "CAST(BASE64_DECODE("
BASE64_END = ") AS BLOB SUB_TYPE TEXT)"
SHA256_HASH_START = "BASE64_ENCODE(CRYPT_HASH(("
SHA256_HASH_MID = " || "
SHA256_HASH_END = ") USING SHA256))"
```

## Brotli

Brotli is not native. Decompression is a UDR, same pattern as the SQLite extension:

```lua
COMPRESS_START = "BROTLI_DECOMPRESS(BASE64_DECODE("
COMPRESS_END = "))"
```

`BROTLI_DECOMPRESS_FUNCTION` creates `BROTLI_DECOMPRESS` with `ENGINE UDR` and external name `brotli_decfn!brotli_decompress`. Build and install: [extras/brotli_udf_firebird/README.md](/elements/001-hydrogen/hydrogen/extras/brotli_udf_firebird/README.md).

## JSON

Firebird 4 has no native `JSON_VALUE` (that arrives in Firebird 6). `JSON_VALUE_FUNCTION` is a UDR (`json_udfn!json_value`). `json_ingest` is PSQL that calls that UDR on the fast path. Both live in [extras/json_udf_firebird/README.md](/elements/001-hydrogen/hydrogen/extras/json_udf_firebird/README.md).

```lua
JSON_INGEST_START = "json_ingest("
JSON_INGEST_END = ")"
JRS = "JSON_VALUE("
JRE = ")"
```

## Other macros

`${DUMMY_TABLE}` is `FROM RDB$DATABASE`. A bare `SELECT` needs that clause.

`${DROP_CHECK}` refuses a drop when the table has rows (`SELECT … FROM RDB$DATABASE WHERE EXISTS`).

`${REORG}` is a SQL comment. Firebird does not need DB2's reorg-after-alter.

`${SESSION_SECS}` is `DATEDIFF(SECOND FROM CAST(:SESSION_START AS TIMESTAMP) TO CURRENT_TIMESTAMP)`.

Date arithmetic uses `DATEADD(MINUTE, 0 +/- n, CURRENT_TIMESTAMP)` so a bound parameter is not a unary minus.

## SQL rewrites in database.lua

`database.lua` rewrites three Firebird-only shapes before the SQL is sent:

- Multi-row `INSERT … VALUES (…), (…)` becomes `UNION ALL` from `RDB$DATABASE`.
- `ADD COLUMN` / `DROP COLUMN` drops the word `COLUMN`.
- `NOT NULL DEFAULT` is reordered to `DEFAULT … NOT NULL`.
